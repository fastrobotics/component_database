# Nvida Jetson Nano 4GB Developer Kit
- Model Number: 945-13450-0000-000

# OS Compatability
| OS                             | Compatability                                                        |
| ------------------------------ | -------------------------------------------------------------------- |
| Ubuntu 18.04 LTS               | Native Support                                                       |
| Ubuntu 20.04 LTS (ROS1 Noetic) | Nvidia does not support.  Community created support                  |
| Ubuntu 22.04 (or higher)       | Board limits to Linux Kernel 4.9.  Only option is Dockerc container. |

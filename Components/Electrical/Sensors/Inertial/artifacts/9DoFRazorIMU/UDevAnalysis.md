# UDEV Rules
sudo nano /etc/udev/rules.d/50-custom-usb.rules
```udev
# Sparkfun Razor 9DOF IMU
SUBSYSTEM=="tty", ATTRS{idVendor}=="1b4f", ATTRS{idProduct}=="9d0f", ATTRS{serial}=="?*", PROGRAM="/usr/bin/bash -c 'echo %s{serial} | tail -c 5'", SYMLINK+="imu_%s{manufacturer}_%c"

```
Then reload:
```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```
For IMU1: `/dev/imu_SparkFun_183F`
For IMU2: `/dev/imu_SparkFun_2115`
